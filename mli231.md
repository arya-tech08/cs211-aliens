- **Link to the question article:** https://www.geeksforgeeks.org/problems/count-ways-to-reach-the-nth-stair-1587115620/1
- **My solution:**

\```


int countWays(int n) {
    if (n <= 2) {
        return n;
    }

    int first = 1;
    int second = 2;

    for (int i = 3; i <= n; i++) {
        int current = first + second;
        first = second;
        second = current;
    }

    return second;
}


\```
